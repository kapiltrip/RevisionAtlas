# AHB Handwritten Notes Intake

[Back to AHB](../README.md)

This folder is reserved for Kapil's original AHB handwritten pages. No pages
have been supplied yet, so no content has been invented.

When pages arrive, they will be handled in source order:

1. preserve the original scan or photos;
2. give each page a stable descriptive filename;
3. render every page inline in the AHB notes;
4. explain the visible timing, signals, equations, or diagrams page by page;
5. mark corrections against ARM IHI 0033C; and
6. keep the handwritten explanation separate from the corrected RTL guide.
