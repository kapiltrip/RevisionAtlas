# Repository Guides

[Back to RevisionSolved](../../../README.md)

This directory contains repository-wide rules and workflows. Subject knowledge
stays inside its subject folder; these files explain how that knowledge is
written, revised, expanded, and maintained.

- [Content Standard](CONTENT_STANDARD.md) defines what counts as a deep,
  technically useful explanation.
- [Revision Method](REVISION_METHOD.md) defines closed-book retrieval sessions,
  review marks, and the spaced schedule.
- [Roadmap](ROADMAP.md) defines the admission gate and growth sequence for new
  subjects.
- [Workflow Notes](WORKFLOW_NOTES.md) records solved setup problems and faster,
  repeatable implementation workflows.

Live coverage and due review items belong in the separate
[tracking area](../tracking/README.md).
