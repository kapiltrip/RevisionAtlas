## Core terms

The clock-mode meanings are verified against [Microchip’s SPI transfer-mode table](https://onlinedocs.microchip.com/oxy/GUID-A299F4E7-F38C-4DF5-96C0-A87B9F519156-en-US-4/GUID-8A5B8750-B99E-4176-834E-E44E98F4A098.html).

| Term | Meaning |
|---|---|
| **SPI — Serial Peripheral Interface** | A synchronous serial interface in which a controller supplies `SCK`, selects a peripheral, and shifts data through separate controller-to-peripheral and peripheral-to-controller paths. |
| **SCK** | The serial clock generated by the controller. Its idle level and sampling/setup edges are selected by CPOL and CPHA. |
| **MOSI / MISO** | Traditional names meaning controller/master-out peripheral/slave-in and the reverse. They describe fixed wire direction, not which direction currently carries useful payload. `COPI/CIPO` is a role-neutral alternative. |
| **Chip select (`CS` or `SS`)** | A usually active-low, out-of-band signal that selects the peripheral and often frames a transfer. Exact start/end behavior is device-specific. |
| **Full duplex** | One bit can shift in each direction during the same SCK cycle because SPI has separate data paths. One direction may contain dummy bits and still be electrically active. |
| **Shift register** | Sequential storage that moves its bit pattern by one position per selected clock event, exposing one outgoing serial bit while accepting one incoming bit. |
| **CPOL — clock polarity** | Selects the idle SCK level: LOW for `CPOL=0`, HIGH for `CPOL=1`. |
| **CPHA — clock phase** | Selects which SCK edge samples data: `CPHA=0` samples on the leading edge and `CPHA=1` on the trailing edge. The opposite edge changes or sets up the next bit. |
| **Leading / trailing edge** | The leading edge is the first transition away from the idle level; the trailing edge is the second transition back. “Leading” is not always rising. |
| **Bit order** | The choice to shift MSB-first or LSB-first. SPI does not impose one universal order; both endpoints must match the peripheral’s specified convention. |
