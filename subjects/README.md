## Management rules

- Use the root [content standard](../CONTENT_STANDARD.md) for every definition, acronym, symbol, “why” answer, and citation.
- Use [How to Revise a Subject](../REVISION_PLAN.md) for the retrieval and spaced-review cycle.
- Update the [subject dashboard](../tracking/README.md) when coverage or the next action changes.
- Add a future subject as a sibling folder using the [subject template](../templates/subject-template.md), never inside an unrelated topic.
- Do not call an academic subject complete when only the present source set is complete. Use **revision-ready for current scope**.

The [Future Plan](../FUTURE_PLAN.md) defines the admission gate and proposed order for additional subjects.
